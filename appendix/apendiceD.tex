\chapter{Python Orchestration and Diagnostic Scripts}
\label{app:python-scripts}

This appendix provides the complete Python source code for the automated experimental runners utilized throughout the factorial evaluation. It contains the baseline workload sampling engine for Scenario~1, the deterministic log-scraping Root Cause Analysis (RCA) harness for the Vanilla Kubernetes baseline (Scenario~3), and the distributed trace/metric correlation agent interfacing with Grafana Tempo and Prometheus APIs for the PANOPTES architecture (Scenario~4).
